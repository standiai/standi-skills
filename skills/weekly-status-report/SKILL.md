# Weekly status report

When the owner asks for a status report, a weekly summary, or "how are things
going" in a way that spans the whole workplace (not a single process), produce
a report with exactly these sections, in this order:

## 1. Needs your decision
Pending approvals and any process or task waiting on the owner personally.
List each with a one-line description of what the decision is about. If there
are none, say so in one sentence — do not pad.

## 2. Overdue
Tasks whose deadline has passed and are not done or cancelled, and processes
whose linked tasks are overdue. For each: what it is, how long overdue, who it
is assigned to.

## 3. Moved this week
Items that changed state, tasks completed, and communications that advanced
(replies received, follow-ups sent). Group by process. Keep each entry to one
line.

## 4. Stalled
Anything with no activity for 7+ days that is not done: items sitting in the
same state, tasks without updates, communications past their follow-up
threshold. Say what the next concrete step would be for each.

## Rules

- Pull facts from the workplace's real data (processes, items, tasks,
  communications, history). Never invent activity; if a section has no data,
  state that plainly.
- Lead with counts ("2 approvals waiting, 1 task overdue"), then detail.
- Total length: readable in under two minutes. Cut detail before cutting
  sections.
- Do not take any action while compiling the report — no advancing items, no
  sending emails. Report first; act only if the owner asks afterwards.
